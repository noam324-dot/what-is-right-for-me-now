# מה נכון עבורי עכשיו?

אפליקציית ווב עברית ורגועה ליצירת רגע קצר של תשומת לב ובחירה. נבנתה כפרויקט חדש עם Next.js, TypeScript ו־App Router.

## הפעלה מקומית

1. התקינו Node.js 20 ומעלה.
2. הריצו `npm install`.
3. הריצו `npm run dev` ופתחו את הכתובת שמופיעה במסוף.

בדיקות: `npm run typecheck` ולאחר מכן `npm run build`.

## נתונים ופרטיות

המצבים, הפעולות האישיות, המונה והמשוב נשמרים רק ב־localStorage בדפדפן. למבנה הנתונים יש `version` כדי לאפשר הגירות עתידיות.

## פרסום עתידי

הפרויקט לא מחובר כרגע לשירות פרסום. לאחר אישור התוכן והתצוגה ניתן בעתיד ליצור מאגר Git, להעלות אותו לשירות אחסון מתאים (למשל Vercel), לבחור Next.js כ־framework ולהריץ את פקודת ה־build הרגילה `npm run build`. יש לבדוק שוב את הגדרות הפרטיות לפני פרסום.
